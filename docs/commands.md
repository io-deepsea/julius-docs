# **Lista de Comandos**

Aqui estão todos os comandos disponíveis no **Julius**. O prefixo padrão é `/`.

## 🔍 Busca e Economia
Estes são os comandos principais para você encontrar preços baixos agora.

| Comando | Descrição | Exemplo |
| :--- | :--- | :--- |
| `/pechinchar [jogo]` | Busca o menor preço atual em várias lojas (Steam, Nuuvem, Epic). | `/pechinchar Elden Ring` |
| `/conselho` | Recebe falas divertidas do Julius Bot. | `/conselho` |


## 💡 Dicas de Uso
* **Seja específico:** Em vez de `/pechinchar Mario`, use `/pechinchar Mario Odyssey` para resultados mais precisos.
* **Privacidade:** O Julius respeita as regras do seu servidor. Se você preferir, pode usar os comandos de busca no canal de `#bot-commands` para não poluir o chat geral.
