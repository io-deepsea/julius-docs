#**Bem vindo(a)!**
Seja bem vindo(a) a documentação do Julius Bot.

O **Julius** é um bot de Discord focado em rastreio de preços justos e acessíveis de jogos eletrônicos para quem quer aquele desconto que faz falta na hora de ser assaltado pelos novos lançamentos, especialmente quando precisa pagar os boletos e não tem um dólar para gastar. O foco aqui é mais economia para o seu bolso.

## O Monitor de Preços 💸
Tal qual o personagem do seriado, o bot acredita que se você não comprar nada, o desconto é maior — mas, se for comprar, que seja pelo menor preço disponível. O Julius varre as principais lojas (Steam, Nuuvem, Epic e outras) para garantir que você não gaste um centavo a mais do que o necessário. Se o jogo que você quer baixou de preço, o Julius te avisa antes mesmo de você pensar em abrir a carteira.

## Open Source (Java/Spring)
O projeto é totalmente aberto e transparente. Se você é dev e quer ajudar a melhorar a lógica de rastreio, sugerir novas integrações ou otimizar o sistema, o código está disponível no GitHub. Sinta-se em casa para abrir um Pull Request ou apontar melhorias.

## Apoie o Projeto ☕

Manter o Julius online 24/7 exige recursos de servidor e, principalmente, tempo de desenvolvimento. Como o criador do bot também tem boletos que não param de chegar, qualquer ajuda é bem-vinda para manter as luzes acesas e o código fluindo.

Você pode contribuir via Pix ou ver como ajudar na nossa página de Apoio. Cada real ajuda a manter o servidor ligado e o dev motivado!
